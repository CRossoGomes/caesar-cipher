#caesar-cipher

## Objetivo:
O objetivo desse projeto é criar um pequeno script que encripte e decripte cifras baseado na lógica da "Cifra de César"
 
- - -

## Funcionamento
O funcionamento é simples: Digite ## python <nome_do_arquivo> ##, selecione o modo (encriptando ou decriptando) e o deslocamento das letras. Depois disso o script retornara sua mensagem.

- - -

## Planos Futuros
Pretendo desenvolver outros algorítmos de criptografia, como cifra de Vigenére, RC4 e um mini-RSA.
